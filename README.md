# Homebrew tap for Brink

```bash
brew install --cask semihtalii/brink/brink
```

[Brink](https://github.com/semihtalii/brink) — Claude Code, Codex and Cursor usage limits on the edge of your Mac screen.

Brink isn't in the main `homebrew-cask` repo yet (that needs notarization and a bit more age), so this tap is the official install path until then. The cask is updated on every release.
